# Roadmap

Briefly's MVP covers the full loop: create a brief, share a link, client fills it in from their phone, review and export. These are the next steps. Comment on an issue or open one if you'd like to work on something.

## Next

- [ ] **More templates** — e-commerce, photographer, hair salon, clinic, personal brand.
- [ ] **Email notifications** when a client submits (opt-in, uses the existing SMTP settings).
- [ ] **Reminders** for clients who haven't finished, with consent and configurable timing.
- [ ] **Per-question change requests** — ask the client to redo one answer instead of reopening the whole brief.
- [ ] **Webhooks** on submission (Linear, Slack, Notion, Zapier, n8n…).

## Later

- [ ] **Template builder** — create and edit questions from the UI, including conditional logic.
- [ ] **Team workspaces** — invite collaborators, shared clients and briefs.
- [ ] **Comments and approvals** on answers.
- [ ] **Proposal / contract generation** from answers (templating, no AI required).
- [ ] More languages (Catalan, Portuguese, French…).

## Done

- [x] Authentication (email/password, optional GitHub/Google)
- [x] Clients and briefs, statuses and dashboard
- [x] Declarative templates with snapshots per brief
- [x] Mobile-first multi-step questionnaire with validation and autosave
- [x] Secure uploads with thumbnails and metadata stripping
- [x] Revocable, expiring private links
- [x] Review screen, Markdown / JSON / ZIP export, in-app notifications
- [x] Workspace branding on the questionnaire
- [x] Spanish and English
- [x] Docker image and Compose setup
