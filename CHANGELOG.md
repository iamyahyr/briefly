# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-10-27

First public version.

### Added

- Accounts with email and password, optional GitHub and Google sign-in, password reset.
- Clients: create, edit, search and delete.
- Briefs from the “Local business website” template, with title, target date and questionnaire language.
- Private client links with optional expiry, revocation and regeneration.
- Mobile-first, five-step questionnaire with per-step validation, autosave and resume.
- Secure uploads for logos, photos and PDFs with thumbnails and metadata stripping.
- Review screen, Markdown / JSON / ZIP export, statuses and in-app notifications.
- Workspace branding (name, logo, accent colour) on the questionnaire.
- Spanish and English interface.
- Docker image, Compose setup and automatic migrations.
